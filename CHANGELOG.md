# Changelog

## 2.0.0 — 2026-08-24

- Полностью удалён локальный Ollama/LangChain/RAG runtime.
- Удалены n8n, Postgres, Qdrant и генератор биржевых видео.
- Добавлен прямой асинхронный Mistral Chat Completions API.
- Добавлена короткая сессионная память с TTL и командой `/clear`.
- Approval-flow переведён на изолированное состояние пользователя.
- Callback-кнопки ограничены администратором; ссылки одноразовые и временные.
- Добавлен лёгкий защищённый `systemd` unit для VPS с 1 ГиБ RAM.
